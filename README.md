# 情绪小绘本 · Kids Emotion H5

> 给 3-6 岁孩子的情绪启蒙互动绘本。10 个故事，7 种交互模式，一个 HTML 文件。

陪伴比答案更重要——让孩子用身体而不只是脑袋去理解情绪：看见它、命名它、回应它。

## 在线预览

打开 `index.html` 直接看，或起一个本地服务器：

```bash
python3 -m http.server 8910
# 打开 http://localhost:8910/
```

## 功能

- 🎭 **10 个情绪故事**：生气、不舍、害羞、委屈、害怕、想念、嫉妒、紧张、孤单、开心
- 🎯 **7 种交互模式**：表情匹配、身体地图、抚摸安抚、吹气魔法、情境选择、点击唤醒、摇晃互动
- 💭 **"今天你的心情是哪个"** 选择器作为主入口，根据孩子当下感受推荐故事
- 🔊 **语音播报**（Web Speech API），自动朗读旁白、提示、过渡台词
- 📖 **家长指南页**：发展心理学背景、三层交互意义、每个故事的讨论引导
- 🎨 **绘本风 SVG**：扁平颜色、软描边、大头小身、统一视觉语言

## 三层交互（来自 plan.text）

| 层 | 目的 | 例子 |
|---|---|---|
| **参与式** | 让孩子"进入"故事 | 抚摸、吹气、点击唤醒 |
| **识别式** | 让孩子"看见"情绪 | 表情匹配、身体地图 |
| **表达式** | 让孩子"说出"感受 | 今天的心情、给角色选反应 |

## 设计原则

- **情绪要具象**——3-6 岁靠画面理解情绪，文字解释他听不懂
- **4-6 个场景就够**——注意力 3-8 分钟，多了会走神
- **按钮 ≥ 44px**——精细动作还在发育
- **只用「点」和「滑」**——不要拖拽
- **交互融入叙事**——不是答题，而是「帮小熊做点什么」

## 技术栈

- **单文件 vanilla HTML / CSS / JS**，无构建、无依赖
- **SVG 插画**，全部 inline，无外部资源
- **Web Speech API** for 语音播报（zh-CN，自动挑选最自然的可用声音）
- **DeviceMotion API** for 摇晃互动（无传感器时降级为点击）
- **localStorage** 持久化语音开关
- 移动端优先（375-480px viewport），桌面通过响应式自适应

## 给爸爸妈妈

如果你打算用这个绘本陪孩子读：

1. **坐到孩子旁边** — 不是把手机塞过去就走
2. **读完聊一聊** — "你上次也生过气吧？是什么样子？"
3. **不评价情绪** — "生气也没关系"比"不要生气"管用一千倍
4. **一次一本就够** — 情绪需要消化时间

更详细的指南在应用里的「完整家长指南」页面。
